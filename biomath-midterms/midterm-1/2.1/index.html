Graph f(x) = x² and g(x) = x² + 3 on the same axes.
(a) What can you say about the slopes of the tangent lines to the two graphs at the point x = 0? x = 1? x = 2? x = a, where a is any value?
AnswerThey are equal at every x: the tangent lines are parallel
Full solutiong is f shifted up by 3, so at each x the tangent lines are parallel: at x = 0 both slopes are 0; at x = 1 both are 2; at x = 2 both are 4; at x = a both are 2a.
(b) Explain why adding a constant to any function will not change the value of the derivative at any point.
AnswerThe graph only shifts up or down, so its slopes do not change
Full solutionAdding a constant shifts the graph vertically without changing its shape, so the slope (the derivative) at any point stays the same.

Question 1 of 83
Lecture Question
A function is a rule that:
A. Takes certain numbers as inputs and gives some of them no output
B. Takes certain numbers as inputs and may give each several outputs
C. Takes certain numbers as outputs and assigns to each a definite input
D. Takes certain numbers as inputs and assigns to each a definite output

D. Takes certain numbers as inputs and assigns to each a definite output

Definition: a function is a rule that takes certain numbers as inputs and assigns to each a definite output number.

Each input has exactly one output.

Question 2 of 83
Lecture Question
The set of all input numbers of a function is called the:
A. Domain
B. Intercept
C. Range
D. Dependent variable

A. Domain

The domain is the set of all input numbers. The input is called the independent variable (x, t, …).

Domain = inputs (x). Range = outputs (y).

Question 3 of 83
Lecture Question
The set of all resulting output numbers of a function is called the:
A. Independent variable
B. Domain
C. Range
D. Interval

C. Range

The range is the set of resulting output numbers. The output is called the dependent variable (y, f(x), f(t), …).

Range = outputs.

Question 8 of 83
Lecture Question
A quantity such as the date, which takes only certain isolated values, is called:
A. Interval
B. Continuous
C. Discrete
D. Constant

C. Discrete

Discrete quantities take only certain isolated values (like dates). Continuous quantities, such as time, can be any real number.

Discrete = separate points; continuous = no gaps.

Question 9 of 83
Lecture Question
The set of numbers t such that a ≤ t ≤ b is written in interval notation as:
A. [a, b], a closed interval
B. {a, b}, a set of two numbers
C. (a, b), an open interval
D. (a, b], a half-open interval

A. [a, b], a closed interval

[a, b] is a closed interval: a and b are included. (a, b) is an open interval: a and b are not included.

Square brackets include the endpoints; round brackets exclude them.

3. Horizontal & Vertical Intercepts

Question 39 of 83
Lecture Question
An input value x = a is a horizontal intercept of f if:
A. f(a) = a
B. f(0) = a
C. f(a) = 0
D. a = 0

C. f(a) = 0

x = a is a horizontal intercept (x-intercept, a zero of the function) if f(a) = 0. An output y = b is a vertical intercept if f(0) = b.

Horizontal intercept: the output is zero.

Question 40 of 83
Lecture Question

B. The zeros of the function
C. The vertical intercepts
D. The slopes of the function

B. The zeros of the function

Horizontal intercepts are also called the zeros of the function, because f(x) = 0 there.

Zeros = where the graph meets the x-axis.

Question 41 of 83
Lecture Question
How many vertical intercepts can a function have?
A. At most one
B. Exactly two
C. Any number
D. Always at least two

A. At most one

There is only one vertical intercept for a function (at most one: there is none if x = 0 is not in the domain, as in the snowfall table), because x = 0 can have only one output f(0).

One input (x = 0) → one output.

Question 42 of 83
Lecture Question
To find the vertical intercept from a formula y = f(x), you:
A. Substitute y = 0 and find x
B. Find the largest value of f(x)
C. Solve f(x) = 0 for x
D. Substitute x = 0 and find y = f(0)

D. Substitute x = 0 and find y = f(0)

Vertical intercept from a formula: substitute x = 0, i.e. find y = f(0). Horizontal intercepts: solve f(x) = 0 for x (and exclude x-values not in the domain).

Vertical intercept → set x = 0.
